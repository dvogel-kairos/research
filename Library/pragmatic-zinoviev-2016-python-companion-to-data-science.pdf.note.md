## Currency, and this is the significant finding

**This edition is from 2016. It is ten years old.** For a specification that is a
neutral fact; for a practitioner book on the Python data science toolchain it is
not. The pandas, numpy and scikit-learn APIs it documents have all moved
substantially since, and pandas in particular has had breaking changes and a
major version release in that window.

Do not cite this source for current library behaviour, current API surface, or
current recommended practice without checking the claim against present-day
documentation. It remains usable for concepts that do not date: what a dataframe
is, what a join does, how a workflow is shaped.
